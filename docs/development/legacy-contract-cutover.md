# 旧 OTLP 合同切换

本文记录从 Python prototype 到原生 Rust receiver 的一次性行为切换。冻结输入是 [`contracts/legacy-otlp-v1.json`](../../contracts/legacy-otlp-v1.json)，机器可读决策权威是 [`contracts/legacy-otlp-v1-disposition.json`](../../contracts/legacy-otlp-v1-disposition.json)。Baseline file 保持不可变，disposition 为每个 frozen case 记录当前 response 与 normalized projection。

Case classification 比较 request acceptance、response status/wire mapping 和 allowlisted semantic projection。把 prototype 的两个 table 替换为 typed domain schema 属于整体 cutover，单独的物理 schema 差异不会把语义等价 case 变成 `intentional_change`。

## Frozen case disposition

| Frozen case                         | Native path                               | Disposition          | 审计结果                                                                      |
| ----------------------------------- | ----------------------------------------- | -------------------- | ----------------------------------------------------------------------------- |
| `json-response-completed`           | JSON、identity、completed call            | `intentional_change` | 保留 allowlisted call；JSON success 使用标准空 OTLP response。                |
| `protobuf-response-completed`       | Protobuf、identity、completed call        | `preserved`          | 空 Protobuf success 与 allowlisted call 等价。                                |
| `gzip-json-response-completed`      | JSON、gzip、completed call                | `intentional_change` | 保留 gzip decode 与 call；JSON success 使用标准 OTLP mapping。                |
| `gzip-protobuf-response-completed`  | Protobuf、gzip、completed call            | `preserved`          | Gzip decode、空 Protobuf success 与 call 等价。                               |
| `json-metadata-only`                | JSON、identity、conversation metadata     | `intentional_change` | 保留 typed metadata，不创建 model call；canonical storage 发生预期变化。      |
| `protobuf-metadata-only`            | Protobuf、identity、conversation metadata | `intentional_change` | 保留 typed metadata，不创建 model call；canonical storage 发生预期变化。      |
| `json-unknown-and-forbidden-fields` | JSON unknown fields/privacy sentinels     | `intentional_change` | 丢弃 unknown content，保留 allowlisted usage；JSON success 使用标准 mapping。 |
| `protobuf-unknown-wire-field`       | Protobuf field `50000`                    | `preserved`          | Unknown field 在 extraction 前丢弃；空 success 与 call 等价。                 |
| `malformed-json`                    | Invalid JSON                              | `intentional_change` | HTTP 400 返回 JSON `google.rpc.Status` 与 `otlp_json_decode_failed`。         |
| `malformed-protobuf`                | Invalid Protobuf                          | `intentional_change` | HTTP 400 返回 Protobuf `google.rpc.Status` 与 `otlp_protobuf_decode_failed`。 |
| `malformed-gzip-json`               | Invalid gzip declared as JSON             | `intentional_change` | HTTP 400 返回 JSON `google.rpc.Status` 与 `otlp_gzip_decode_failed`。         |

`codex-monitor-telemetry` 的 `legacy_contract` tests 读取两个 authority，验证精确 11-case coverage、文件与 fragment hashes、每个重建 request SHA，并证明每个 forbidden marker 位于至少一个 reviewed case。执行测试让每个 body 通过 bounded decoder、typed extractor、HTTP router 与 commit-before-ack processor，再提交到假的 consumer-owned observation sink，对照 typed projection、response 和 closed diagnostics。storage crate 的投影测试与 engine 产品集成目标另行证明 observation sink 到 SQLite 的组合路径；这种分层避免 telemetry 为测试而反向依赖 storage。

## 保持的行为

| 行为                      | Native contract                                                                                                                                       | 证据                                                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| OTLP logs endpoint        | Exporter 继续发送 `POST /v1/logs`，listener 只绑定 loopback。                                                                                         | [`http.rs`](../../crates/codex-monitor-telemetry/src/http.rs)、[`receiver.rs`](../../crates/codex-monitor-telemetry/src/receiver.rs) |
| Request encodings         | 支持 Protobuf JSON、binary Protobuf、identity 与 gzip；response 不设置 `Content-Encoding`。                                                           | Frozen gzip cases 与 telemetry decoder/HTTP tests                                                                                    |
| Completed-call projection | Conversation/thread identity、source event time、model、reasoning effort、四类 token、event name、stream kind、surface 与 client 保持 frozen values。 | `legacy_contract` typed sink projection assertions 与 storage projection tests                                                       |
| Metadata extraction       | `codex.conversation_starts` 只形成 metadata observation，不形成 token event 或 completed call。                                                       | `otlp::tests::metadata_event_does_not_create_a_completed_call`                                                                       |
| Unknown fields            | Unknown JSON attributes 与 Protobuf wire fields 在 typed allowlist boundary 前丢弃。                                                                  | `decoder::tests::unknown_protobuf_wire_fields_are_discarded_before_extraction`                                                       |
| Privacy boundary          | Raw OTLP、prompt、response、tool/reasoning data、paths、account/auth values 与 unknown attributes 不进入 SQLite 或 structured diagnostics。           | Frozen typed-sink/diagnostic marker assertions 与 storage privacy-surface tests                                                      |
| Legacy import             | 支持的 legacy database 只读打开，只导入 reviewed historical fields；raw-only content 忽略且 replay 幂等，来源不修改。                                 | [`legacy_import.rs`](../../crates/codex-monitor-storage/src/legacy_import.rs) tests                                                  |

## 有意改变的行为

| 变化                          | Prototype                                                                      | Native behavior 与证据                                                                                                                                                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Standard OTLP success         | JSON 返回自定义 `{ok, log_records, token_events}`。                            | JSON 返回空 `ExportLogsServiceResponse` mapping `{}`；Protobuf 返回空 encoded message。                                                                                                                                                             |
| Strict media types            | `Content-Type` 含 `json` 就选择 JSON，其他尝试 Protobuf。                      | 只接受 `application/json`（可带 `charset=utf-8`）与 `application/x-protobuf`；见 [`decoder.rs`](../../crates/codex-monitor-telemetry/src/decoder.rs)。                                                                                              |
| Encoding-matched errors       | Decode error 始终使用 ad-hoc JSON `{error}`。                                  | Permanent failure 返回 HTTP 400 `google.rpc.Status`，编码与已验证 request 一致。                                                                                                                                                                    |
| Partial success               | Summary 只统计 token rows，没有 OTLP partial success。                         | Rejected registered records 写入 `ExportLogsPartialSuccess`，accepted records 仍原子 commit。                                                                                                                                                       |
| Retryable persistence failure | 没有闭合 OTLP retry contract。                                                 | Durable commit 后才 ack；retryable failure/deadline 返回 HTTP 503/code `14`，permanent 返回 HTTP 400/code `3`；见 [`processor.rs`](../../crates/codex-monitor-telemetry/src/processor.rs)。                                                         |
| Limits/deadline               | Decompression 与 processing 没有共享 bounded contract。                        | Wire bytes、expanded bytes、decode work、完整 request 与 receiver shutdown 均有固定上限。                                                                                                                                                           |
| Dashboard API                 | OTLP process 内暴露 unauthenticated `/`、`/api/stats`、`/api/events`。         | OTLP router 只暴露 `POST /v1/logs`；Dashboard 使用 authenticated `/api/v1`、session cookie 与 CSRF；见 [`routing.rs`](../../crates/codex-monitor-dashboard/src/routing.rs)和[`security.rs`](../../crates/codex-monitor-dashboard/src/security.rs)。 |
| Runtime entry point           | Prototype CLI 拥有 `--port`、`--db`、`--session-index` 并可 bootstrap Python。 | Packaged Tauri host 管理 lifecycle/storage；只保留 bounded `--import-legacy <absolute-sqlite-path>` 数据操作；启动解析见 [`startup.rs`](../../crates/codex-monitor-host/src/startup.rs)。                                                           |
| Legacy privacy migration      | 可原地 destructive rebuild/purge raw tables。                                  | Import read-only 且 additive，unsafe schema 失败关闭，来源不变。                                                                                                                                                                                    |
| Configuration fallback        | 缺失 reasoning effort 可由本机 config 填充。                                   | OTLP source 只发出 registered allowlisted evidence，缺失值保持缺失；见 [`otlp.rs`](../../crates/codex-monitor-telemetry/src/otlp.rs)。                                                                                                              |
| Event-time fabrication        | 缺失 timestamp 可用 HTTP receive time。                                        | `time_unix_nano` 只可 fallback 到 source-provided `observed_time_unix_nano`；两者都缺失则拒绝。                                                                                                                                                     |
| Unregistered token events     | 带 token-like fields 的任意 event 可形成 token row。                           | 只有 registered `codex.sse_event` 可形成 completed call；`codex.conversation_starts` 只形成 metadata。                                                                                                                                              |
| Storage shape                 | 直接持久 `codex_token_events` 与 `codex_conversations`。                       | Typed observations、canonical calls/conversations、source health 与 downstream work 规范化并原子提交。                                                                                                                                              |
| Diagnostics                   | Error 可依赖 parser/handler string。                                           | 只暴露 closed event/error code 与 bounded metadata，不含 raw header、parser chain、payload excerpt 或 source identifier。                                                                                                                           |

Python OTLP harness 已删除。两个 native contract tests 与 baseline SHA 持续通过时，cutover 才有效。未来有意行为变化必须在同一 change 更新 disposition authority 与本表，不能重写 frozen baseline。`pnpm check:no-legacy-runtime` 防止 executable、script 或 shim 恢复旧 runtime path。
