# 架构决策记录

ADR 记录已经接受、会影响运行时架构、隐私、storage、跨平台行为或主要依赖的选择。每份记录包含状态、背景、决策和影响。接受后的记录不可修改；架构发生变化时增加新 ADR，并通过 `Supersedes` 关系说明替代项。

文件使用四位序号与简短 slug。ADR 0001–0006 的英文原件是不可变历史权威，中文伴随译本用于当前阅读并链接原件。ADR 0007 起使用简体中文作为权威语言。
